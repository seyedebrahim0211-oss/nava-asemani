# هویت بصری «نوای آسمانی»

نام انتخابی پروژه (قابل تغییر): **نوای آسمانی** — شعار: **هر نوا، راهی به نور**.

## نشان
- **محراب هندسی**: فرم الهام‌گرفته از قوس ایرانی‌ـ‌اسلامی، بدون استفاده از نشان رسمی هیئت یا نهاد مذهبی.
- **سه خط صوتی**: نشان‌دهنده کتابخانه شنیداری، حرکت و موسیقیِ کلام.
- **قوس تکرارشونده**: اشاره به کاشی‌کاری ایرانی بدون شلوغی بصری.
- آیکن واقعی در `app/src/main/res/drawable/logo_mark.xml` به‌صورت Android Vector است.
- نسخه SVG مستقل در `branding/logo.svg`، بدون وابستگی به فونت‌های اختصاصی.

## چیدمان
- راست‌به‌چپ و فارسی در کل اپ.
- موبایل: نوار ناوبری پایین؛ تبلت از عرض ۷۲۰dp: NavigationRail.
- کارت‌ها با گوشه‌های ۱۷ تا ۲۶dp؛ فاصله‌گذاری ۸/۱۲/۱۸dp.
- شش دسته مستقل: مداحی، روضه، سخنرانی، ادعیه، مناجات، قرآن.
- قلم سیستم اندروید برای خوانایی و عملکرد؛ هیچ فایل فونت شخص ثالثی همراه پروژه نیست.
